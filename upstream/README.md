# Upstream-lähteet

Tämä hakemisto sisältää Git-submodulit alkuperäisiin lähdeprojekteihin, joiden avulla kykyä ylläpidetään.

- `finnish-humanizer/`: Harri Sipolan Finnish Humanizer ja AI-patternien taksonomia.
- `suomi-finnish-skill/`: Aku Nikkolan suomen kielenhuollon ja kieliopin ohjeistus.
- `suomettaja-skill/`: Janne Ikolan suomettaja-skill, josta tämä kyky on forkattu.

Lähteet eivät ole ajonaikaisia referenssejä. Kielenhuolto-kyky käyttää kuratoituja tiedostoja `references/`-hakemistossa.

Älä muokkaa `upstream/`-hakemiston tiedostoja suoraan. Päivitä submodulit, tarkista niiden diffi ja siirrä olennaiset muutokset tiedostoihin `references/patterns.md` tai `references/kielioppi.md`.
